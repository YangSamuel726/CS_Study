# CPU란 무엇인가?
CPU는 컴퓨터의 `두뇌`에 해당하는 핵심 부품이다. 또한 메모리에 저장된 명령어를 읽어 들이고, 해석하고, 실행하는 장치이다.

### CPU의 핵심 구성 요소
- 제어장치
- 산술논리연산장치(ALU)
- 레지스터

### CPU의 작동 방식 (기본 사이클)
- 가져오기(Fetch)
- 해석하기(Decode)
- 실행하기(Execute)

### CPU의 성능을 결정하는 중요 지표
- 클럭 속도
- 코어와 스레드
- 캐시 메모리
