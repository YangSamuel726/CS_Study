# 빌드

소스 코드와 필요한 리소스를 실제로 실행하거나 배포할 수 있는 결과물로 변환하는 전체 과정을 **빌드**라고 한다.

이 빌드 과정은 C언어를 기준으로 3단계로 구성된다. 전처리 - 컴파일 - 링킹 이 그것이다.

## 전처리

전처리 과정은 소스 코드에 있는 전처리문을 처리하고 번역 단위로 바꿔주는 역할을 한다.

예를 들어

```C
#include <stdio.h>
```

이 코드는 `stdio.h`라는 헤더파일의 내용을 현재 위치에 넣으라는 의미이다. 이 과정이 컴파일 이전 전처리 과정에 처리된다.

## 컴파일

컴파일 과정은 전 처리가 완료된 번역 단위를 목적코드로 변환해주는 역할을 한다. 이때 각 번역 단위를 기준으로 검사가 진행된다.

검사 과정에서 문법적으로 문제가 없는지를 검사한다. 중요한 건 이때 선언부만 있으면 구현 부분이 없어도 문법적으로 이상이 없이 넘어간다는 점이다.

## 링킹

선언 부분의 실제적인 구현부분을 연결해주는 과정이다. 선언만 있고 구현은 없다면 실행에 큰 오류가 날 것이다. 그렇기에 실제적으로 해당 선언의 구현을 연결해줌으로 실제 실행이 가능하도록 하는 것이 링킹 과정에서 이루어진다.

더 정확히는 각 목적 파일에 남아 있는 심볼의 참조를 다른 목적 파일이나 라이브러리에 존재하는 정의와 연결하는 과정이다.
