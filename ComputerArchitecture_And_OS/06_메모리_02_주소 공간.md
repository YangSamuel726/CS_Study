# 메모리 주소 공간
주소에는 두 종류가 있다. **물리 주소**와 **논리 주소**이다. 물리 주소는 메모리 하드웨어가 사용하는 주소이고, 논리 주소는 CPU와 실행 중인 프로그램이 사용하는 주소이다.

논리 주소와 물리 주소는 명령어나 데이터의 위치를 각각 프로그램의 주소 공간과 실제 메모리의 주소 공간을 기준으로 나타낸 주소이다.

## 물리 주소
물리 주소란 컴퓨터의 물리 메모리에서 특정 위치를 식별하는 주소이다.

이 안에서 프로그램들의 위치가 실시간으로 달라지기도 하며 프로그램 실행시 매번 적재 위치가 달라지기도 한다.

## 논리 주소
논리 주소란 프로그램이 자신의 주소 공간에서 명령어나 데이터의 위치를 나타내는 데 사용하는 주소이다.

논리 주소를 통해 메모리 상에서 프로그램의 실제 배치 위치가 달라져도 같은 논리 주소로 같은 데이터에 접근할 수 있게 된다.

## 메모리 관리 장치(MMU)
메모리 관리 장치는 프로그램의 시작 주소(물리 주소)를 베이스 레지스터에 저장하고 범위를 한계 레지스터에 저장하여 관리한다. 이를 통해 프로그램이 존재하는 메모리 공간에 CPU가 논리 주소로 접근하려 할때 메모리 공간이 유효한지를 검사해준다.

만약에 CPU가 한계 레지스터보다 높은 논리 주소에 접근하려고 하면 인터럽트(트랩)를 발생시켜 실행을 중단한다.

예를 들어 베이스 레지스터에 100이, 한계 레지스터에 150이 들어있다고 하자.
![MMU 작동 방식 1](./Description_Images/06_메모리_02_MMU%201.jpg)\
CPU가 논리 주소 100으로 메모리에 접근하려 하면 MMU는 논리 주소가 한계 범위 안에 있는지 검사한 후 베이스 레지스터 값에 논리 주소를 더하여 실제 데이터가 있는 물리 주소로 변환한다.
![MMU 작동 방식 2](./Description_Images/06_메모리_02_MMU%202.jpg)\
만약에 CPU가 논리 주소 200으로 접근하려 한다면 이는 범위를 벗어나는 주소이므로 접근이 불가능하다.
![MMU 작동 방식 2](./Description_Images/06_메모리_02_MMU%203.jpg)


## 왜 이렇게 나눠논 것일까?
CPU와 실행중인 프로그램은 메모리 몇 번지(물리 주소)에 무엇이 저장되어 있는지 다 알지 못한다. 정확히는 일일히 물리주소를 알 필요가 없다. 메모리에 저장된 정보는 시시각각 변하고 같은 프로그램을 실행하더라도 실행할 때마다 적재되는 주소가 달라진다. 그렇기에 프로그램의 시작 물리 주소와 할당된 범위만 따로 관리 해주는 장치가 있다면 CPU는 프로그램 각각의 0번지부터 시작하는 논리 주소를 사용해 시시각각 변하는 메모리 정보에서 원하는 데이터 위치에 정확하게 접근할 수 있게 된다. 이때 시작 물리 주소와 할당된 범위를 관리하며 논리 주소를 물리 주소로 변환해주는 장치가 CPU내부에 **메모리 관리 장치**(Memory Management Unit, MMU)이다.
