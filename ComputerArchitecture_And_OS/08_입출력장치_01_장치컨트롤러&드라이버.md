# 입출력장치
입출력장치는 컴퓨터 외부와 컴퓨터 내부가 데이터를 주고받게 해 주는 장치이다.

컴퓨터에는 CPU와 메모리만 있지 않다. 스피커, 모니터, 키보드, 마우스 등과 같은 입출력장치와 외장 하드 디스크나 USB 메모리 등 보조기억장치가 컴퓨터에 주렁주렁 달려 있다.

이러한 입출력장치들은 어떻게 컴퓨터와 정보를 주고 받을까? 결론을 먼저 말하면 장치 컨트롤러와 장치 드라이버를 통해 가능하다.

## 장치 컨트롤러
일반적으로 입출력장치에는 종류가 많아 정보를 주고받는 방식을 규격화하기가 어렵다. 또한 CPU와 메모리의 데이터 전송률과 입출력장치의 전송률이 맞지 않아 통신이 어려워진다.

> [!Note]
> **전송률**이란 데이터를 얼마나 빨리 교환할 수 있는지를 나타내는 지표이다.

이와 같은 이유로 입출력장치는 컴퓨터에 직접 연결되지 않고 **장치 컨트롤러**라는 하드웨어를 통해 연결된다. 

장치 컨트롤러는 대표적으로 다음과 같은 역할을 가진다.
- CPU와 입출력장치 간의 통신 중개
- 오류 검출
- 데이터 버퍼링

### 데이터 버퍼링
데이터 버퍼링이란 무엇일까? **버퍼링**이란 전송률이 높은 장치와 낮은 장치 사이에 주고받는 데이터를 **버퍼**라는 임시 저장 공간에 저장하여 전송률을 비슷하게 맞추는 방법이다. \
장치 컨트롤러는 일반적으로 전송률이 높은 CPU와 일반적으로 전송률이 낮은 입출력장치와의 전송률 차이를 데이터 버퍼링으로 완화한다.

### 장치 컨트롤러 내부
실제로는 복잡하지만 우리가 기억해야 할 것은 **데이터 레지스터, 상태 레지스터, 제어 레지스터** 세 가지이다.

> [!Note]
> 상태 레지스터와 제어 레지스터는 하나의 레지스터로 사용되기도 한다.

**데이터 레지스터**는 CPU와 입출력장치 사이에 주고받을 데이터가 담기는 레지스터이다. 데이터 레지스터가 데이터 버퍼링에서 버퍼 역할을 한다. 주고받는 데이터가 많은 입출력장치의 경우 레지스터 대신 RAM을 사용하기도 한다.

**상태 레지스터**에는 입출력장치가 입출력 작업을 할 준비가 되었는지, 작업이 완료되었는지, 오류는 없는지 등의 상태 정보가 저장된다.

**제어 레지스터**에는 입출력장치가 수행할 내용에 대한 제어 정보와 명령을 저장한다.

이러한 레지스터에 담긴 값들은 시스템 버스를 타고 CPU나 다른 입출력장치로 전달되기도 하고 장치 컨트롤러에 연결된 입출력장치로 전달된다.


## 장치 드라이버
**장치 드라이버**란 장치 컨트롤러의 동작을 감지하고 제어함으로써 장치 컨트롤러가 컴퓨터 내부와 정보를 주고받을 수 있게 하는 프로그램이다. 입출력장치를 컴퓨터와 연결하기 위한 소프트웨어적인 통로인 것이다.

장치 드라이버를 인식하고 실행하는 주체는 운영체제이다. 장치 드라이버는 운영체제와 장치 컨트롤러 사이에서 서로의 요청을 중개해주는 역할을 한다.
