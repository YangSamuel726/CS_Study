# ISA

ISA는 Instruction Set Architecture의 약자로 명령어 집합 구조를 의미한다. 또한 하드웨어(CPU)와 소프트웨어를 이어주는 인터페이스이다. ISA는 하드웨어 구조와 설계에 영향을 미치며 ISA에 따라 같은 비트패턴도 서로 다른 의미의 명령어가 될 수 있다.

CISC와 RISC는 명령어 체계(ISA)를 설계하는 두 가지 대표적인 방향이다.

## CISC
CISC는 Complex Instruction Set Computer의 약자로 '복잡한 명령어 집합을 활용하는 컴퓨터'를 의미한다. CISC는 다양하고 강력한 기능의 명령어 집합을 제공한다. 때문에 다양한 명령어를 담을 수 있는 **가변 길이 명령어**를 활용한다.

x86 계열이 CISC에 속한다.

### 장점

1. 메모리 공간을 절약할 수 있다.
2. 명령어 하나가 여러 작업을 수행할 수 있음

### 단점

1. 파이프라인이 효율적으로 명령어를 처리하기 어렵다.
2. 구조가 복잡해서 설계가 어렵다.
3. 상대적으로 처리 속도가 느리다.
   - 복잡한 명령어를 실행하는데 여러 클럭이 필요하기 때문
4. 다양한 명령어가 있지만 일부(대략 20%) 명령어만 자주 쓰인다.

메모리 성능이 좋아지면서 CISC의 장점이 의미가 없어지고 현대 CPU의 명령어 파이프라인은 높은 성능을 위한 핵심이기에 CISC 기반 CPU는 성장에 한계가 있다.

## RISC

CISC의 한계는 다음과 같았다.

1. 빠른 처리를 위해 명령어 파이프라인이 활용되어야 한다. 이를 위해 **명령어 길이와 수행 시간**이 짧고 규격화되어 있어야 한다.
2. 어차피 자주 쓰이는 명령어만 줄곧 사용된다. 이를 위해 자주 쓰이는 기본적인 명령어를 작고 빠르게 만드는 것이 중요하다.

이런 원칙하에 등장한 것이 RISC이다. RISC는 Reduced Instruction Set Computer의 약자이다. 이름처럼 RISC는 CISC에 비해 명령어의 종류가 적다. 또 짧고 규격화된 명령어, 되도록 1클럭 내외로 실행되는 명령어를 지향한다. 즉, RISC는 **고정 길이 명령어**를 활용한다. 이런 특징은 명령어 파이프라이닝에 최적화되어 있다.

ARM 계열이 RISC에 속한다.

## 비교

|             CISC             |           RISC           |
| :--------------------------: | :----------------------: |
|    복잡하고 다양한 명령어    |   단순하고 적은 명령어   |
|       가변 길이 명령어       |     고정 길이 명령어     |
|    다양한 주소 지정 방식     |   적은 주소 지정 방식    |
| 여러 클럭에 걸쳐 명령어 수행 | 1클럭 내외로 명령어 수행 |
|   파이프라이닝하기 어려움    |  파이프라이닝하기 쉬움   |
