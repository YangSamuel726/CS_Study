# 메모리
메모리는 프로그램의 명령어와 데이터를 저장해 두고 CPU가 주소를 지정해서 읽거나 쓸 수 있게 하는 장치이다.

메모리는 **주기억장치**라고 불리며 종류에는 크게 **RAM**과 **ROM**, 두 가지가 있다.

# RAM
RAM은 Random Access Memory의 약자로 현재 실행할 명령어와 처리할 데이터를 담아 두는 메모리이다. 이름의 *Random Access*는 주소를 지정해서 원하는 위치에 바로 접근할 수 있다는 뜻이다. 또한 전원을 끄면 저장된 내용이 사라지는 **휘발성 저장 장치**이다.

RAM의 용량이 클 수록 보조기억장치에서 많은 데이터를 가져와 미리 저장할 수 있다. 이는 많은 프로그램을 동시에 실행할 수 있게 해준다.

RAM의 종류에는 크게 DRAM, SRAM, SDRAM, DDR SDRAM이 있다.

### DRAM
Dynamic RAM의 약자로 저장된 데이터가 동적으로 변하는 RAM을 의미한다. DRAM은 시간이 지나면 저장된 데이터가 점차 사라지는 RAM으로, 데이터의 소멸을 막기 위해 일정 주기로 데이터를 재활성화해야 한다.

이런 단점에도 소비 전력이 비교적 낮고, 저렴하고, 집적도가 높아 대용량으로 설계하기가 용이하기 때문에 사용된다.

### SRAM
Static RAM의 약자로 저장된 데이터가 변하지 않는 RAM을 의미한다. DRAM과 달리 시간이 지나도 저장된 데이터가 사라지지 않고 일반적으로 속도도 더 빠르다.

SRAM은 DRAM보다 집적도가 낮고, 소비 전력이 크며, 가격도 더 비싸기 때문에 '대용량으로 만들어질 필요는 없지만 속도가 빨라야 하는 저장 장치'에 사용된다. 캐시 메모리에서 사용되어진다.

### SDRAM
Synchronous Dynamic RAM의 약자로 클럭 신호와 동기화된, 발전된 형태의 DRAM이다. SDRAM은 클럭에 맞춰 동작하며 클럭마다 CPU와 정보를 주고받을 수 있는 DRAM이다.

### DDR SDRAM
Double Data Rate SDRAM의 약자로 최근 가장 흔히 사용되는 RAM이다. 대역폭을 넓혀 속도를 빠르게 만든 SDRAM으로, 여기서 **대역폭**이란 데이터를 주고받는 길의 너비를 의미한다.

한 클럭에 한번씩 CPU와 데이터를 주고받을 수 있는 SDRAM에 비해 DDR SDRAM은 두 배의 대역폭으로 한 클럭당 두 번씩 CPU와 데이터를 주고받을 수 있다. 즉, 전송 속도가 두 배가량 빠르다. 이런 이유로 한 클럭당 하나씩 데이터를 주고받을 수 있는 SDRAM을 SDR SDRAM이라 부르기도 한다.

DDR2 SDRAM은 DDR SDRAM보다 두 배 넓은 SDRAM이다. DDR3 SDRAM은 DDR2 SDRAM보다 대역폭이 두 배 넓다.

필자가 사용하는 램은 무엇인지 궁금해서 찾아봤다. 필자의 램은 DDR5로 SDR보다 32배 넓은 대역폭을 가진다.
